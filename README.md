# Personal Website

A personal portfolio website showcasing my work, experience, skills, projects, and contact information.

## Overview

This website is designed as a central place to learn more about my professional background and the projects I have worked on.

## Features

- Personal introduction and profile
- Selected projects and work
- Professional experience
- Skills and technologies
- Contact and social links
- Responsive design for different screen sizes

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

## Getting Started

### Prerequisites

Make sure you have Node.js and npm installed.

## Roadmap
